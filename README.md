# Учебная виртуальная машина, вариант 23

Практическая работа № 3, ИКБО-12-25. Ассемблер и интерпретатор на
Python 3.11+. Используется стандартная библиотека, сборка и установка
дополнительных пакетов не требуются.

## Язык ассемблера

Одна команда на строку, в конце обязательна точка с запятой.
Комментарии начинаются с `#`. Регистр имён имеет значение.
Целые операнды задаются десятичными неотрицательными числами.

| Команда | Поля | Действие |
| --- | --- | --- |
| `ACC = 188;` | A=7, B=188 | Загрузить константу в аккумулятор. |
| `ACC = MEM[ACC];` | A=26 | Прочитать память по адресу из аккумулятора. |
| `MEM[771] = ACC;` | A=18, B=771 | Записать аккумулятор по адресу B. |
| `ACC = ACC + MEM[64];` | A=21, B=64 | Прибавить значение памяти к аккумулятору. |

B для константы занимает 23 бита (0–8388607), для адреса — 20 бит
(0–1048575). Программа проверяет диапазоны до формирования кода.
`src/assembler.py` разбирает текст, `src/instructions.py` задаёт
объекты промежуточного представления и проверяет поля.

## Ассемблер

```cmd
run.bat assemble src\examples\specification.asm -o output\spec.bin --test
set "PYTHONPATH=src"
py -3 -m unittest discover -s src\tests -v
```

Ассемблер записывает двоичный файл и сообщает количество команд.
`--test` выводит байты каждой команды в шестнадцатеричном формате.
В коммите первого этапа этот режим выводит поля A и B.
В Git Bash скрипт запускается как `bash run.sh`.

`src/codec.py` кодирует и декодирует команды в little-endian.
A занимает младшие 5 бит, B начинается с бита 5. LOAD занимает
4 байта, READ — 1, STORE и ADD — по 4. Неиспользуемые старшие
биты равны нулю. Декодер проверяет длину, код операции и резервные биты.
`src/output_file.py` заменяет выходной файл после полной записи.
